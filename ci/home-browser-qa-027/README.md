The app uses an in-memory SQLite store and a synthetic supervisor cookie. It binds only to 127.0.0.1 on a dynamic port. Browser routes block external and non-GET/HEAD requests, and service workers are blocked. No real login, production database or user data is used. The Node/browser runtime receives a temporary HOME and minimal environment. Chrome uses its standard sandbox and preinstalled executable; a launch failure is reported without permission, kernel, KVM or security changes.

The workflow is limited to the public repository, first branch-creation event and attempt 1, a standard Ubuntu 24.04 runner, contents:read, checkout without persisted credentials, and 15 minutes. It runs the dependency-free administration/school suite without npm ci. Only official Playwright 1.62.0 is installed to a runner-temporary prefix with scripts and browser download disabled. Existing action pins match prior reviewed browser QA. Ordinary workflow artifacts retain text and screenshots for three days; binaries are never added as Git blobs.
