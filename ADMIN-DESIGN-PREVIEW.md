# Administration design preview

Unpublished design iteration on school-foundation. Numbered backups 007 and 008 retain the prior code; 008 also includes the uncommitted design patch. Adds a dimensional parent container, compact floating section cards, stable icon shapes by section, short labels, visible focus and keyboard-operable native help details. Existing permissions determine available cards. Primary actions and trial-storage notices remain visible.

School subpage uses numbered panels and compact responsive forms; shared panel treatment extends to existing administration pages. This is the first administration design iteration, not a claim that every platform page or every nested section is redesigned. No deployment or PR approval is inferred.

94 regression tests passed. Browser tested hub at 390/1280, keyboard guide opening, and school create/assign/remove/reload flows. Preview images: ../school-verification/hub-390.png and hub-1280.png. Shape mappings are keyed to section identity so permission changes do not renumber visual identity.
