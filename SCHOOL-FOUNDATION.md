# School foundation — phase 1

Extends the existing admin identity, permission, registration and audit systems at /admin/school. Opens supported primary grades 1–6 and named classes. Assigns an existing teacher to each class/subject, an existing child to one class and each teacher to one active administrative supervisor. Assignments can be removed explicitly; replacements never silently overwrite another assignment.

The general supervisor grants school.read and granular school.structure, school.teachers, school.students, school.supervision permissions through existing account controls. Other existing roles receive no new authority automatically. Write grants require school.read. School.read alone shows only grade/class structure; student, teacher and supervision lists require their respective capabilities. Existing teacher invitation and parent/student registration remain in their current sections. Assignment of a supervisor does not grant classroom access, observation or evaluation features.

All mutations reload authority, run inside the existing BEGIN IMMEDIATE transaction and write the existing audit log. Scope checks bind grade/class/teacher/child/admin to the actor's scope. Teacher assignment requires matching grade and subject, and student assignment requires matching grade. Unique constraints reject duplicate assignments. Removal requires the displayed current assignment so a stale form cannot remove a different replacement.
